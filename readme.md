# Базы данных

## Postgres

**1. Запустить контейнер с PostgreSQL:**

```bash
docker compose up -d postgres
```

**2. Подключиться к базе данных:**

```bash
psql -h localhost -p 5432 -U postgres -d appdb
```

| Параметр | Значение    | Описание                          |
| -------- | ----------- | --------------------------------- |
| `-h`     | `localhost` | Хост (проброшенный порт Docker)   |
| `-p`     | `5432`      | Порт PostgreSQL                   |
| `-U`     | `postgres`  | Имя пользователя                  |
| `-d`     | `appdb`     | Имя базы данных                   |

> Пароль еще надо ввести

### Команды

#### Просмотр информации о базе данных

| Команда       | Что показывает                                        |
| ------------- | ----------------------------------------------------- |
| `\l`          | список баз данных                                     |
| `\c имя_базы` | переключиться на другую базу                          |
| `\dt`         | таблицы                                               |
| `\dt+`        | таблицы с размером на диске                           |
| `\d имя`      | структура объекта: столбцы, типы, ключи, индексы       |
| `\d+ имя`     | то же плюс комментарии и статистика                   |
| `\dv / \dm`   | представления / материализованные представления       |
| `\di`         | индексы                                               |
| `\df`         | функции                                               |
| `\dn`         | схемы                                                 |
| `\du`         | роли и их права                                       |
| `\dp`         | права доступа к таблицам                              |
| `\conninfo`   | параметры текущего подключения                        |

#### Настройки вывода и работа с файлами

| Команда                                            | Действие                                                                         |
| -------------------------------------------------- | -------------------------------------------------------------------------------- |
| `\x`                                               | вертикальный вывод (спасение для широких таблиц), "транспонировать таблицу"      |
| `\timing on`                                       | показывать время выполнения запросов                                             |
| `\pset null '(null)'`                              | показывать NULL заметно, а не пустотой                                           |
| `\pset pager off`                                  | не использовать постраничный просмотр                                            |
| `\copy tbl TO 'f.csv' WITH (FORMAT csv, HEADER)`   | выгрузить в CSV на своей машине                                                  |
| `\copy tbl FROM 'f.csv' WITH (FORMAT csv, HEADER)` | загрузить из CSV                                                                 |
| `\o file.txt`                                      | перенаправить вывод в файл (\o без аргумента — вернуть на экран)                 |

#### Редактирование и выполнение запросов

| Команда       | Действие                                               |
| ------------- | ------------------------------------------------------ |
| `\e`          | открыть последний запрос в текстовом редакторе         |
| `\g`          | выполнить последний запрос ещё раз                     |
| `\s`          | история команд                                         |
| `\i file.sql` | выполнить SQL-файл                                     |
| `\watch 2`    | повторять последний запрос каждые 2 секунды            |
| `Ctrl+C`      | прервать ввод недописанного запроса                    |
| `\q`          | выйти
